# ניסוי חציית NAT – הוראות לבודקים

המטרה: לבדוק אם שני מחשבים ברשתות שונות מצליחים להתחבר ישירות, או שהם צריכים
את שרת העזר. כל בדיקה לוקחת דקה.

## מה צריך

- הקובץ `spike-peer.exe` (מורן ישלח לך).
- כתובת שרת העזר – מורן ישלח לך. היא נראית כך:
  `/ip4/1.2.3.4/tcp/4001/p2p/12D3KooW...`
- שני אנשים, **ברשתות שונות** (בית אחר, עבודה, או טלפון בנקודה חמה).
  לא מהרשת הביתית של מורן – משם הבדיקה לא אמינה.

## איך בודקים

**אדם א'** פותח PowerShell בתיקייה של הקובץ ומריץ:

```
.\spike-peer.exe listen <כתובת-השרת>
```

התוכנה תדפיס פקודה שמתחילה ב-`spike-peer dial`. שולחים אותה לאדם ב'.

**אדם ב'** מריץ את הפקודה שקיבל (עם `.\` בהתחלה):

```
.\spike-peer.exe dial <כתובת-השרת> <המזהה-שקיבלת>
```

אחרי עד 30 שניות תופיע שורה שמתחילה ב-`RESULT`. **שולחים אותה למורן**, יחד עם
סוג הרשת של כל צד (סיב בבית / סלולר / עבודה).

## אזהרות שיופיעו

- **Windows SmartScreen** יזהיר שהקובץ לא חתום. זה צפוי בשלב הזה:
  "מידע נוסף" ← "הפעל בכל זאת".
- **חומת האש של Windows** תשאל אם לאפשר גישה לרשת. לאשר לרשתות פרטיות.

## מה התוצאה אומרת

| `path=` | משמעות |
| --- | --- |
| `direct` | החיבור הישיר הצליח – המצב הטוב |
| `relayed` | עבד רק דרך שרת העזר – עובד, אבל איטי יותר ועולה לנו |
| `failed` | לא התחבר בכלל – לשלוח למורן את כל הפלט |
