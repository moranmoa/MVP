## Legend

- **D**: devops can run it with its existing smoke driver (two installed `mvs-core`
  instances driven through the api, as in the v0.2.4 draft smoke: invite, join, post,
  delivery timestamps, `RUST_LOG` greps, relay `circuits_denied`).
- **D+**: the driver almost covers it; the note says what has to be added.
- **M**: manual, in the installed app. Most of it is UI.
- PC **A** is the owner and PC **B** is the member, **on different networks** (for example a
  phone hotspot for B). Use `<relay-domain>` in notes and reports, never the real one.

Report failures with: the step ID, expected vs actual, a screenshot, the diagnostics file
(Settings → Diagnostics → Export), the OS and version, and each PC's network. Never send
the 12 words, an invite link or the data file. Bugs go to `qa/BUGS.md` and the board
(`docs/BOARD.md`) through the PM.

## S1. Join reliability (target: 10/10)

Fixing the v0.2.4 hang (B stuck on "searching" for 120 s while A was online, with no relay
denials) is the main reason for this release. **Any hang fails the release.**

| # | Step | Expected | How |
| --- | --- | --- | --- |
| S1.1 | A creates a fresh server and copies the invite. B joins by link. Repeat with a **new server each time**, 10 times in total. | **10/10** reach "joined" and show the server. Record the time to join for each one. | **D** |
| S1.2 | Same as S1.1, but restart A's core between creating the server and B's join (the stale-entry case). Do this 5 times. | 5/5 join. | **D+**: add a "restart A before join" step |
| S1.3 | B joins while A is offline, then A comes online. | B shows "nobody from the server is online", then joins within 30 s of A coming online, without retrying. | **D+**: add an "A offline at join time" mode |
| S1.4 | 3 of the S1.1 joins, done by hand in the installed app on both PCs. | Same result as the driver. The UI moves from "מחפשים חברים מהשרת…" to the server without a reload. | **M** |
| S1.5 | Relay logs during S1.1–S1.3. | 0 `circuits_denied`. No gossip-disabled WARN lines (the list in the v0.2.4 smoke notes). | **D** |

Pass when there are **10/10 joins** in S1.1, **p95 time to join ≤ 15 s** and no join over 60 s.
Record the 10 times in the PR or report.
