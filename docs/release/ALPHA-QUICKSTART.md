# MVS – התחלה מהירה לאלפא הסגורה

המדריך הזה מיועד למי שהוזמן לאלפא הסגורה. ב-15 דקות בערך תתקינו את MVS,
תיצרו זהות ושרת, תזמינו מחשב שני ותתכתבו.

> זו גרסת אלפא: יהיו באגים. כל דבר מוזר שאתם רואים – ספרו לנו (בסוף הדף כתוב איך).

## 1. הורדה

בדף ה-Release של הגרסה (קיבלתם לינק) מורידים קובץ אחד, לפי המחשב:

| מחשב | הקובץ |
| --- | --- |
| Windows 10 או 11 | `mvs-<גרסה>-windows-x86_64-setup.exe` |
| Linux, כל הפצה | `mvs-<גרסה>-linux-x86_64.AppImage` |
| Ubuntu או Debian (אם מעדיפים התקנה רגילה) | `mvs-<גרסה>-linux-x86_64.deb` |

את קובצי ה-`.zip` וה-`.tar.gz` לא צריך: הם בשביל העדכון האוטומטי.

**בדיקה שהקובץ תקין (לא חובה):** בדף יש גם קובץ `SHA256SUMS`. ב-Windows
(PowerShell): `Get-FileHash .\mvs-<גרסה>-windows-x86_64-setup.exe`, וב-Linux:
`sha256sum mvs-<גרסה>-linux-x86_64.AppImage`. המספר שיוצא צריך להיות זהה
לשורה של אותו קובץ ב-`SHA256SUMS`.

## 2. התקנה

### Windows

1. פותחים את קובץ ה-`setup.exe` שהורדתם.
2. **אזהרת SmartScreen:** בגרסת האלפא הקובץ עוד לא חתום, ולכן Windows יציג
   חלון כחול "Windows הגן על המחשב שלך". לוחצים על **"מידע נוסף"** (More info)
   ואז על **"הפעל בכל זאת"** (Run anyway). זה צפוי, ונעלם כשתהיה חתימה דיגיטלית.
3. מסיימים את ההתקנה. לא צריך הרשאות מנהל: MVS מותקן רק למשתמש שלכם.
4. MVS מופיע בתפריט התחל ובשולחן העבודה.

### Linux – AppImage (בלי התקנה)

```bash
chmod +x mvs-<גרסה>-linux-x86_64.AppImage
./mvs-<גרסה>-linux-x86_64.AppImage
```

לא צריך sudo. אם מופיעה שגיאה על FUSE, מתקינים את `libfuse2`
(ב-Ubuntu: `sudo apt install libfuse2`).

### Linux – ‎.deb

```bash
sudo apt install ./mvs-<גרסה>-linux-x86_64.deb
```

אחר כך MVS נמצא בתפריט היישומים.

## 3. יצירת זהות

בפתיחה הראשונה:

1. **בחירת שפה**, ואז **לפני שמתחילים**, **מדינה** ו**תאריך לידה** (הגיל המינימלי
   הוא 16).
2. **מילות השחזור שלך:** לוחצים **הצגת המילים**, כותבים את 12 המילים **על נייר**,
   לפי הסדר, ולוחצים **כתבתי אותן**.
   - המילים הן החשבון שלכם. מי שמחזיק בהן – שולט בחשבון. אין לנו עותק ואין
     "שכחתי סיסמה".
   - לא מצלמים ולא שולחים לאף אחד.
3. **בדיקה קצרה:** מקלידים את המילים שמתבקשות. בלי הבדיקה הזאת אי אפשר ליצור
   שרת.
4. **איך יקראו לך?** – שם תצוגה (ותמונה, אם רוצים). ליד השם מופיע **קוד הזהות
   שלך**, שעוזר לאחרים לוודא שזה באמת אתם.

כבר יש לכם חשבון ממחשב אחר? בוחרים **כבר יש לי חשבון** ומקלידים את 12 המילים.

## 4. יצירת שרת

1. במסך הבית: **יצירת שרת**.
2. נותנים שם, בוחרים **הגבלת גיל**, ולוחצים **יצירה**.
3. מופיע **השרת מוכן** עם לינק ההזמנה (`mvs://…`). אפשר להעתיק אותו מכאן, או
   אחר כך מתפריט השרת: **אפשרויות שרת** ← **העתקת לינק ההזמנה**.

## 5. הזמנת מחשב שני

1. במחשב השני מתקינים את MVS ויוצרים זהות (שלבים 1–3). זה יכול להיות מחשב של
   חבר או מחשב אחר שלכם עם זהות אחרת.
2. שולחים אליו את לינק ההזמנה (וואטסאפ, מייל, מה שנוח).
3. במחשב השני:
   - **לחיצה על הלינק** פותחת את MVS במסך **הצטרפות לשרת**, עם הלינק כבר
     בפנים. שום דבר לא קורה עד שלוחצים **הצטרפות**.
   - אם הלחיצה לא פותחת את MVS (למשל באפליקציה שלא מציגה `mvs://` כקישור):
     מעתיקים את הלינק, ובמסך הבית בוחרים **הצטרפות בלינק** ומדביקים.
4. MVS מחפש חברים מהשרת ("מחפשים חברים מהשרת…"). **המחשב הראשון צריך להיות
   דלוק ו-MVS פתוח בו**: אין שרת מרכזי שמחזיק את ההודעות, הן עוברות בין
   המחשבים של החברים.

## 6. צ'אט

בוחרים ערוץ בפס הצד (יש ערוץ כללי מוכן), כותבים ולוחצים **שליחה**. ההודעה
מגיעה למחשב השני תוך שנייה בערך.

## טוב לדעת

- **רשת:** האפליקציה מגיעה מוגדרת עם שרת העזר (relay) של הפרויקט, ולא צריך
  להגדיר כלום. שרת העזר רק מחבר בין המחשבים ומעביר מידע מוצפן; הוא לא שומר
  הודעות. הוא רץ על מחשב בבית של בעל הפרויקט, ולכן לפעמים לא יהיה זמין.
- **עדכונים:** בגרסה הזאת העדכון האוטומטי עוד לא פעיל עד שבעל הפרויקט יחתום
  על קובץ העדכון. גרסה חדשה מתקינים מעל הישנה; הנתונים והזהות נשמרים.
- **הסרה (Windows):** בהגדרות ← אפליקציות ← MVS ← הסרה. ההסרה שואלת אם למחוק
  את הנתונים המקומיים; ברירת המחדל היא **לשמור**. הזהות לא נמחקת בלי שתבחרו
  בזה במפורש – וגם אז, בלי 12 המילים אי אפשר לשחזר אותה.
- **הסרה (Linux):** AppImage – מוחקים את הקובץ. ‎.deb – `sudo apt remove mvs-desktop`.
  בשני המקרים הנתונים בתיקיית הבית נשארים.

## דיווח על בעיות

ספרו לבעל הפרויקט (בערוץ שבו קיבלתם את ההזמנה) מה עשיתם, מה ציפיתם שיקרה
ומה קרה בפועל, ובאיזו מערכת הפעלה. צילום מסך עוזר – **רק בלי מילות השחזור**.
