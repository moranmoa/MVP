# B11 – מסך הגדרות השרת (מאוחד)

- **משימה:** B11b + B11c + B11d + ש-4 (ביטול הרחקה) + B7 (הגבלת גיל), במסך אחד. **מקור:** המשוב של הבעלים על v0.2.0: ההגדרות לא נמצאות.
- **האפיון הזה מגדיר את המבנה ואת נקודות הכניסה.** את ההתנהגות של כל חלק לא חוזרים לכתוב כאן: היא נשארת ב-[B11a–d](B11a-d-server-management.md) וב-[B7](B7-age.md), עם ההפניות בטבלה של §2. אם יש סתירה, האפיון הזה קובע את המיקום, והאפיונים האחרים קובעים את ההתנהגות.
- **קבצים צפויים:** `ServerSettings.tsx` (חדש), `ChannelSidebar.tsx`, `ServerMenu.tsx`, `i18n/*.json`
- **בעלים בלבד** (ש-10). מי שאינם בעלים לא רואים את הכפתור ולא את הפריט בתפריט.

## 1. נקודות כניסה

1. **כפתור גלוי:** גלגל שיניים בראש פס הערוצים, בצד ה-end של שם השרת, ליד כפתור הלינק. 32px, עם אזור לחיצה של 44px. `aria-label` = `server.settings.open`, ו-`title` זהה. תמיד מוצג לבעלים, גם בלי hover.
2. **תפריט השרת** (B11a–d §1): הפריט "הגדרות השרת".
3. **תפריט ההקשר של השרת בפס** (B25 §4): "הגדרות השרת".
4. **מהדיאלוג "בעלים לא יכולים לעזוב"** (B11a–d §2): פותח ישר את "אזור מסוכן".
5. **קיצור מקלדת:** אין באלפא.

## 2. מבנה

דיאלוג גדול, באותו פריסה כמו הגדרות האפליקציה: ניווט בצד ה-start, תוכן בצד ה-end. בראש: אייקון השרת (32px), השם, ו"סגירה" (X).

| דף | מה בו | ההתנהגות לפי |
| --- | --- | --- |
| **כללי** (`server.settings.nav.general`) | אייקון, שם, תיאור. "שמירה" / "ביטול שינויים" | B11a–d §3.1 (סעיפים 1–3, 6) |
| **גיל** (`server.settings.nav.age`) | 3 אפשרויות הגבלת הגיל, עם הניסוח של UX-15, ואזהרה בהעלאה | B7 §6, B11a–d §3.1 סעיף 4 |
| **ערוצים** (`server.settings.nav.channels`) | רשימת הערוצים, "יצירת ערוץ", ולכל ערוץ "עריכה". ‏#general בלי מחיקה | B11a–d §4 |
| **הזמנה** (`server.settings.nav.invite`) | הלינק, "העתקה", "ביטול הלינק…" | B11a–d §5 |
| **חשבונות שהורחקו** (`server.settings.nav.removed`) | הרשימה ו"ביטול ההרחקה". כשאין הרחקות: `server.removed.empty` במקום להסתיר את הדף | B11a–d §5א |
| **אזור מסוכן** (`server.settings.nav.danger`) | "סגירת השרת…" עם אישור כפול. בניווט: טקסט בצבע `--danger` ומופרד בקו | B11a–d §3.2 |

- **הדף שנפתח:** "כללי". מנקודת כניסה 4: "אזור מסוכן".
- **"שמירה"** קיימת רק בדפים "כללי" ו"גיל". שאר הדפים פועלים מיד, כל פעולה עם האישור שלה.
- **שינויים שלא נשמרו:** מעבר דף או סגירה כשיש שינויים ב"כללי" או ב"גיל" פותחים אישור קצר בתוך הדף: `server.settings.unsaved` עם "שמירה" / "ביטול השינויים" / "חזרה". Esc = "חזרה".
- **באופליין:** כמו ב-B11a–d §6. אחרי שמירה מופיעה השורה `server.settings.pendingSync`.

## 3. טלפון ו-200%

- **טלפון (מתחת ל-40rem):** מסך מלא. הניווט הופך לרשימה (כמו הגדרות האפליקציה ב-PR #10). בחירה מחליפה את המסך, ו"חזרה" חוזר לרשימה. "שמירה" sticky בתחתית.
- **200% / 24px:** הניווט עובר מעל התוכן כרשימה נגללת. אין גלילה אופקית. שם שרת של 48 תווים בכותרת: שורה אחת עם `…` ו-`title` מלא.

## 4. מקלדת וקורא מסך

- הדיאלוג: `role="dialog"`, `aria-labelledby` = כותרת עם שם השרת. הפוקוס הראשוני: הפריט הנבחר בניווט.
- **הניווט:** `role="tablist"` אנכי, עם `aria-orientation="vertical"`. חצים למעלה ולמטה, ו-Enter או רווח לבחירה. התוכן הוא `role="tabpanel"`. בטלפון זו רשימה רגילה של כפתורים.
- **מעבר דף:** הפוקוס עובר לכותרת הדף (`h2`, `tabIndex=-1`).
- **Esc:** סוגר, חוץ ממקרה של שינויים שלא נשמרו (§2). אחרי סגירה, הפוקוס חוזר לכפתור או לפריט שפתחו את הדיאלוג.

## 5. CoreApi

אין שינוי מעבר לטבלה של B11a–d §8 ול-B7 §9. הדף "גיל" קורא ל-`updateServer({ ageRestriction })`.

## 7. בדיקות קבלה

1. **גלוי:** בעלים רואים את גלגל השיניים בלי hover. מי שאינם בעלים – אין כפתור ב-DOM.
2. **כל הדפים** נפתחים, ובכל אחד ההתנהגות לפי האפיון שבטבלה של §2 (הבדיקות של B11a–d §10 ושל B7 §11 עוברות דרך המסך הזה).
3. **שינויים שלא נשמרו:** שינוי שם ← מעבר ל"ערוצים" ← אישור. "חזרה" משאיר את השינוי.
4. **מקלדת:** חצים בניווט, והפוקוס עובר לכותרת הדף. Esc מחזיר את הפוקוס לגלגל השיניים.
5. **טלפון:** רשימה ← דף ← "חזרה". אין גלילה אופקית ב-375px וב-200%.
