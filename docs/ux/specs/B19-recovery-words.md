- **משימה:** B19 (P1, אבן דרך M1) · **ממצאים:** UX-05, UX-06, QA-01, U1 · **תלוי ב:** B2 (המילים נשמרות בליבה עד הבדיקה, ו-`getRecoveryWords` עובד אחרי הפעלה מחדש)
- **מקורות:** `docs/reviews/ux-review-1.md`, `docs/reviews/po-review-1.md` (§8, B19, ש-3), `qa/BUGS.md` (QA-01)
- **קבצים צפויים:** `RecoveryWords.tsx`, `Onboarding.tsx`, `Shell.tsx` (דיאלוג הבדיקה), `SettingsScreen.tsx` (חשבון), `app/onboardingResume.ts` (חדש), `styles/app.css`, `i18n/*.json`, `core/api.ts`, `core/mock.ts`

## 1. מטרה

1. המילים לא מוצגות עד שמבקשים, כי גיימרים משדרים מסך.
2. סדר הקריאה חד-משמעי בכל כיוון.
3. בבדיקה מסומנות רק המילים השגויות.
4. השדות לא גולשים מהכרטיס (U1).
5. רענון או קריסה בזמן ההרשמה לא מאבדים את המילים (QA-01).

## 2. המסכים

### 2.1 "מילות השחזור שלך" (שלב 5 מתוך 7)

מלמעלה למטה:

1. שורת התקדמות "שלב 5 מתוך 7" (ללא שינוי).
2. כותרת `onb.words.title`.
3. תיבת האזהרה (`onb.words.warning` + `onb.words.tip`, ללא שינוי בניסוח – מטבלת המיקרו-קופי של האפיון).
4. **שורה חדשה** `onb.words.english`, בטקסט משני – רק בממשק העברי (ש-3).
5. **הרשת** – בשני מצבים:
   - **מוסתרת (ברירת מחדל):** 12 תאים עם המספר ו-"•••••" במקום המילה. מעל הרשת, במרכז, שכבה עם הכפתור הראשי **"הצגת המילים"** (`onb.words.reveal`), ומתחתיו `onb.words.revealHint`. את המילים לא מכניסים ל-DOM במצב הזה, כדי שגם קורא מסך והקלטת מסך לא יראו אותן.
   - **מוצגת:** המילים בתאים. מעל הרשת, בצד ה-end, כפתור משני קטן **"הסתרת המילים"** (`onb.words.hide`), שמחזיר למצב המוסתר.
6. כפתור ראשי **"כתבתי אותן"** (`onb.words.written`). מושבת עד שהמילים הוצגו פעם אחת לפחות. כשהוא מושבת מוצגת מתחתיו השורה `onb.words.writtenHint` (מחוברת ב-`aria-describedby`).

**הרשת:**
- תמיד `dir="ltr"`, גם בעברית (המילים באנגלית, ש-3).
- **סדר בעמודות:** `grid-auto-flow: column`.
  - ברוחב כרטיס ≥ 24rem: 3 עמודות × 4 שורות. עמודה 1 = 1–4, עמודה 2 = 5–8, עמודה 3 = 9–12.
  - מתחת ל-24rem (טלפון, 200%): 2 עמודות × 6 שורות. 1–6, 7–12.
  - container query על `.onb-card` (לא media query), כדי שזה יעבוד גם בקנה מידה גבוה.
- **מספר:** "1." בגודל 0.875rem, `font-weight: 600`, צבע `--text-muted`. לא `aria-hidden` (קורא מסך צריך את המספר).
- **מילה:** `font-family: var(--font-mono)`, 1rem, `font-weight: 600`.
- העתקה, גזירה וגרירה חסומות (PR #10, נשאר).

```css
.word-grid { display: grid; grid-auto-flow: column; grid-template-columns: repeat(3, minmax(0, 1fr)); grid-template-rows: repeat(4, auto); gap: 0.5rem; }
@container onb (max-width: 24rem) { .word-grid { grid-template-columns: repeat(2, minmax(0, 1fr)); grid-template-rows: repeat(6, auto); } }
.onb-card { container: onb / inline-size; }
```

### 2.2 "בדיקה קצרה" (שלב 6 מתוך 7)

ללא שינוי במבנה, עם התיקונים האלה:
- **המיקומים מגיעים מהליבה:** בכניסה לשלב, הממשק קורא ל-`getRecoveryChallenge()` ומציג את 3 המיקומים שהוחזרו. `pickPositions()` בממשק יורד. כך אי אפשר לבדוק מיקום שהליבה לא בחרה (§6).
- **U1/UX-05:** `.check-fields { grid-template-columns: repeat(3, minmax(0, 1fr)) }` ו-`.check-fields input { min-width: 0; width: 100% }`. מתחת ל-24rem של הכרטיס – עמודה אחת.
- השדות בסדר עולה של המיקום, תמיד `dir="ltr"` בתוך השדה. הסדר של השדות עצמם בשורה עוקב אחרי כיוון הממשק (הנמוך מימין בעברית).
- **שגיאה:** רק השדות השגויים מקבלים `aria-invalid="true"` וגבול אדום. השגיאה מופיעה מתחת לשדות (`onb.check.wrong`, ב-plural). הפוקוס עובר לשדה השגוי הראשון, והטקסט בו מסומן (`select()`).
- כשמתחילים להקליד בשדה שגוי, הסימון יורד **רק ממנו**.
- **הצלחה:** שורה ירוקה `onb.check.ok` עם אייקון ✓, ל-600ms, ואז מעבר לשלב הפרופיל (UX-27). הבדיקה מקומית – בלי עיכוב מלאכותי.
- "להציג את המילים שוב" חוזר ל-2.1, במצב **מוסתר**.
- **יותר מדי ניסיונות:** אחרי 5 בדיקות שנכשלו, הליבה שורפת את האתגר ו-`checkRecoveryWords` נדחה עם `too-many-attempts`. השדות והכפתור "בדיקה" מושבתים, ובמקום השגיאה מופיע `onb.check.tooMany` עם כפתור ראשי "הצגת המילים" (`onb.words.reveal`). הכפתור חוזר ל-2.1 (או, בדיאלוג של 2.3, לרשת המוסתרת). רק אחרי ש-`getRecoveryWords()` הצליח, הממשק מבקש אתגר חדש.

### 2.3 דיאלוג הבדיקה מהבאנר ומההגדרות

היום הדיאלוג (`dialog === 'check'`) מבקש 3 מילים, אבל אין בו דרך לראות אותן. מי שלחץ "אעשה את זה אחר כך" ולא כתב את המילים נתקע.

- בתחתית הטופס: קישור **"הצגת המילים"** (`onb.words.reveal`).
- לחיצה מחליפה את תוכן הדיאלוג ברשת של 2.1, במצב **מוסתר**, עם הכפתור "הצגת המילים". רק לחיצה עליו קוראת ל-`getRecoveryWords()`.
- מתחת לרשת: כפתור ראשי "לבדיקה עכשיו" (`banner.recovery.action`), שחוזר לטופס הבדיקה. המילים נמחקות מה-state ברגע שעוזבים את הרשת.
- אותו דיאלוג נפתח מ"הגדרות ← חשבון ← לבדיקת המילים".

## 3. חזרה אחרי רענון או קריסה (QA-01)

- **בממשק:** מפתח `localStorage` בשם `mvs.onboarding.v1`, עם הערך `"words"`, `"check"` או `"profile"`. נכתב בכניסה לכל אחד מהשלבים האלה, ונמחק בסיום ההרשמה. **אין בו מילים.**
- **בטעינה:** אם יש זהות (`getIdentity()` לא `null`) **וגם** המפתח קיים → `Onboarding` נפתח באותו שלב. ב-`words` המצב הוא **מוסתר**, והמילים נטענות רק בלחיצה על "הצגת המילים", דרך `getRecoveryWords()`.
- אם `identity.recoveryChecked` כבר `true` והמפתח הוא `words` או `check` → מדלגים ל-`profile`.

## 5. מקלדת וקורא מסך

- בכניסה לשלב: הפוקוס על הכותרת (כמו היום). Tab הבא – "הצגת המילים".
- "הצגת המילים" / "הסתרת המילים" הם **אותו כפתור** עם `aria-expanded` ו-`aria-controls="word-grid"`. הפוקוס נשאר עליו אחרי הלחיצה.
- הרשת: `<ol id="word-grid" aria-label=…>`. כשהיא מוסתרת – `aria-label` = `onb.words.gridHidden`, והתאים `aria-hidden="true"`. כשהיא מוצגת – כל `li` מוקרא "1. lantern".
- "כתבתי אותן" מושבת: `aria-disabled="true"` (לא `disabled`), כדי שיישאר בסדר ה-Tab וה-`writtenHint` יוקרא. לחיצה עליו במצב הזה לא עושה כלום.
- בבדיקה: כל שדה עם `aria-describedby` לשגיאה. השגיאה עם `role="alert"`.
- שורת ההצלחה `role="status"`.

## 8. בדיקות קבלה

**אוטומטיות:**
1. **רכיב:** במצב מוסתר אין אף מילה ב-DOM (`container.textContent` לא מכיל אף אחת מ-12 המילים).
2. **רכיב:** "כתבתי אותן" עם `aria-disabled="true"` עד הלחיצה הראשונה על "הצגת המילים".
3. **רכיב:** סדר ה-DOM הוא 1–12. מיקום חזותי: `li:nth-child(2)` נמצא **מתחת** ל-`li:nth-child(1)` (אותו `left`, `top` גדול יותר).
4. **בדיקה:** עם 2 נכונות ו-1 שגויה – רק השדה השגוי `aria-invalid`, והוא ב-`document.activeElement`.
4a. **מגבלת ניסיונות (דמה):** 5 בדיקות שגויות ← השדות מושבתים ו-`onb.check.tooMany` מוצג. `checkRecoveryWords` עם מיקום שלא באתגר ← נדחה עם `not-allowed`. `getRecoveryChallenge` אחרי שריפה ← נדחה עד `getRecoveryWords`.
5. **QA-01:** הרשמה עד שלב המילים, `page.reload()` – האפליקציה נפתחת על "מילות השחזור שלך" במצב מוסתר. לחיצה על "הצגת המילים" מציגה את אותן 12 מילים. בדיקת QA-01 ב-`explore.spec.ts` עוברת מ-`test.fail()` לירוק.
6. **U1:** ברוחב 1366, ב-375 וב-200%, הרוחב של `.check-fields` קטן או שווה לרוחב התוכן של `.onb-card`.
7. **אבטחה:** אחרי ההרשמה, אין מילים ב-`localStorage` (הבדיקה הקיימת ב-`screenshots.mjs` נשארת), ו-`mvs.onboarding.v1` נמחק.
