## מוסכמות

- **מחרוזות:** כל אפיון כולל טבלה עם מפתח, עברית ואנגלית. dev-ui הוא היחיד שכותב לקבצי ה-JSON. `⁨` ו-`⁩` (FSI/PDI) נכתבים בקובץ בדיוק כך. כלל העטיפה מוגדר ב-B17 §4.
- **ניסוח:** עברית ניטרלית מגדרית. מחליפים רק שמות עצם ממוגדרים ביחיד. "מי ש…" ורבים נשארים. מחרוזות מטבלת המיקרו-קופי של האפיון לא משתנות.
- **שם המוצר:** MVS. לינקים: `mvs://`.
- **קוד זהות (UX-19, הוכרע):** ליד השם בכל הודעה, 0.75rem, `--text-muted`, `aria-hidden`.
- **שינויי חוזה:** כל שינוי ב-`CoreApi` מסומן "שינוי חוזה" בטבלת ה-CoreApi של האפיון.
- **בדיקת קבלה:** כל אפיון מסתיים ברשימת צילומים עם מספר, שם קובץ ומה רואים בהם, ל-`ui/scripts/screenshots.mjs`. טווחי מספרים: B17 70–79, B19 80–89.
